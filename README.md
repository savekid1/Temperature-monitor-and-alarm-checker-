Temperature Monitor and Alarm Checker

What it does

The Temperature Monitor and Alarm Checker is a Python program designed to monitor the temperature of a machine using five temperature readings entered by the user. It stores the readings in a list and calculates the highest, lowest, and average temperatures. It also checks whether the machine is operating within a safe temperature range and displays an alarm warning when the temperature exceeds the set limit.

How to run it

1. Install Python 3 on your computer or install Pydroid 3 on your Android phone.
2. Download or copy the Python file named "temperature_monitor.py".
3. Open the file using Python or Pydroid 3.
4. Run the program.
5. Choose the monitoring option and enter five temperature readings in Celsius.

My own twist

I added a Machine Status Report feature that identifies whether a machine is operating normally, approaching its temperature limit, or overheating. I also added an Individual Reading Check that examines each temperature reading separately and identifies dangerous temperatures.
